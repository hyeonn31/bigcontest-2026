# 2026 빅콘테스트 — 기후위기 취약상권 영향 분석

한국정보통신진흥협회 2026 빅콘테스트, **AI데이터분석** 분야 참가 프로젝트.
기후 이벤트(비·폭염 등)가 상권 소비에 미치는 영향을 업종·시간대·방문객 유형별로 분석한다.

- 분석 지역: 서울 강남구, 강원 춘천시
- 분석 기간: 2025-07-01 ~ 2025-12-31 (184일)
- 사용 데이터: SK텔레콤 유동인구, 신한카드 소비, 기상청 ASOS 시간자료
- 일정: 결과물 제출 ~10/26, 1차 서류심사 11/5~9, 2차 PT 11/18~20

## 폴더 구조

| 폴더 | 내용 |
| --- | --- |
| `scripts/` | 집계·병합·분석 파이썬 스크립트 |
| `data/processed/` | 날짜×지역 등으로 집계한 가공 데이터 (CSV) |
| `eda_output/` | EDA·검정 결과 텍스트 |
| `figures/` | 그래프 |
| `notes.md` | 데이터 구조, 분석 과정, 발견, 진행 상황 (작업 일지) |

## 원본 데이터

대회 제공 원본(SK텔레콤·신한카드·기상청 CSV/TXT)은 재배포 제한과 용량 문제로 이 저장소에 포함하지 않는다 (`.gitignore`).
스크립트는 로컬의 `data/shinhan_card/`, `data/sk_flow_pop/`, `data/weather/`에 원본이 있다는 전제로 작성되어 있고, 경로는 작성자 PC 기준 절대경로다.

## 진행 상황

세부 내용은 [notes.md](notes.md) 참고.
