### 분석

#### Part1. EDA — 결제금액은 극단적으로 치우쳐 있다

![결제금액 분포](figures/ts_at_distribution.png)

소수 거액 결제 때문에 원본 스케일에서는 대부분이 0 근처에 붙어 있고, log10 스케일에서 종 모양에 가깝다 → 이상치를 잘라내지 않고 **로그 변환**. 종속변수를 log(금액)으로 두면 계수가 곧 "몇 % 변화"로 해석된다.

#### Part2. 모형 — 로그선형 회귀 + 보정 3종

```
log(핵심 소비) = α + Σ 월 더미 + Σ 요일 더미 + β₁·공휴일
                 + β₂·약한비(1~30mm) + β₃·호우(30mm↑) + β₄·폭염(33℃↑) + ε
효과(%) = (exp(β) − 1) × 100     ← '비 안 온 평범한 날' 대비 소비 변화율
```

- **HAC 표준오차**: 비가 며칠씩 이어지는 자기상관 보정 (Newey-West, 최대 3일)
- **FDR 보정**: 업종 145개를 동시 검정할 때 우연한 유의성 제거 (Benjamini–Hochberg, q<0.1)
- **상호작용항**: 두 그룹의 반응 차이 자체를 직접 검정

```python
# scripts/common.py — 모든 검정이 공유하는 함수. 스크립트마다 넣는 변수(terms)만 다르다
def fit_hac(g, y, terms):
    X = pd.get_dummies(g[["month", "weekday"]].astype(str), drop_first=True, dtype=float)
    for c in terms:
        X[c] = g[c].astype(float)
    X = sm.add_constant(X).loc[y.index]
    return sm.OLS(y, X).fit(cov_type="HAC", cov_kwds={"maxlags": 3})
```

### 결론

#### 1. 무엇을 발견했나

1. **비가 많이 오면 상권 소비가 실제로 줄어든다.** 춘천은 호우일(하루 30mm 이상) 핵심 소비가 평소보다 8.6% 줄었다. 같은 달·같은 요일·공휴일 여부를 맞춰 놓고 비교한 값이다.
2. **줄어드는 정도는 '누가 쓰는 돈이냐'에 따라 크게 다르다.** 같은 춘천, 같은 호우일인데 다른 시·도에서 온 방문객의 소비는 19.1% 줄었고, 강원도 주민의 소비는 6.4%만 줄었다. 방문객 쪽 감소가 약 3배 크다.
3. **이 차이는 우연이 아니다.** 호우 기준을 15~40mm로 바꿔도, 전날 비의 영향을 넣어도 결과가 유지됐다.
4. **반대로, 그럴듯했지만 데이터가 뒷받침하지 않은 주장도 있다.** "강남은 지하철·지하상가 덕분에 비에 덜 흔들린다"는 설명은 두 지역 차이를 직접 검정하자 근거가 없었다(p=0.40). "방문객이 많은 업종일수록 취약하다"는 가설도 업종 단위로는 성립하지 않았다. 폭염은 두 지역 모두 소비에 영향이 없었다.

#### 2. 그래서 무슨 의미인가

비가 와도 그 지역에 사는 사람의 소비는 비교적 덜 줄지만, 먼 곳에서 오려던 사람은 **방문 자체를 미루거나 취소하는 것**으로 보인다(방문 취소를 직접 관측한 것은 아닌 해석). 그래서 매출에서 외지 손님 비중이 높은 상권일수록 날씨 충격을 크게 받는다.

이를 바탕으로 **"외지 방문객 매출 비중이 높은 상권 = 기후 취약 상권"** 이라는 기준을 제안한다. 춘천은 매출의 약 21%가 다른 시·도 거주자에게서 나온다.

#### 3. 어디에 쓸 수 있나

- **지자체 · 관광공사**: 카드 결제 기록에는 손님이 사는 시·도가 남는다. 상권별로 외지 손님 매출 비중만 계산하면, 설문조사 없이 이미 있는 데이터로 "비가 오면 타격이 클 상권"을 미리 골라 호우 예보 때 지원 대상을 정할 수 있다.
- **카드사 · 금융**: 업종별로 "호우일 매출이 평소보다 몇 % 빠지는가"를 수치로 가지고 있다(예: 춘천 골프장 −57%, 커피전문점 −17%, 편의점 −8%). 소상공인 대상 날씨 보험이나 대출 상품을 만들 때 업종·지역별 위험도를 매기는 출발점이 될 수 있다.
- **관광지 소상공인**: 호우 예보가 나오면 외지 손님의 예약 취소가 늘 것을 예상하고 취소 유연화·실내 대체 프로그램 등으로 대비할 수 있다. (데이터로 효과를 검증한 처방은 아닌 추정)
- **다른 지역으로 확장**: 같은 방법을 전주·경주·여수 같은 다른 관광도시에도 그대로 적용할 수 있다.
